 Responsive Website

## Project Description

This project is a simple responsive website created using HTML5 and
external CSS3.

The website demonstrates desktop, tablet and mobile responsive layouts.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Responsive Images
